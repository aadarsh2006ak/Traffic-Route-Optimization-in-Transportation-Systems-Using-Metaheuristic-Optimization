## 1. Problem Definition & Formulation

Urban Vehicle Routing Problem with Time Windows (VRPTW) and Dynamic Congestion on weighted directed road networks $G = (V, E)$.

### 1.1 Road Network Graph Model
- $V = \{0, 1, 2, \dots, n\}$: Set of network vertices, where $0$ is the Central Depot and $1 \dots n$ are delivery/customer nodes.
- $E = \{(i, j) \mid i, j \in V, i \neq j\}$: Directed edges representing road links.

Each directed edge $(i, j)$ is characterized by a time-varying composite weight function:
$$w(i, j, t) = \alpha \cdot \text{distance}(i, j) + \beta \cdot \text{travel\_time}(i, j, t) + \gamma \cdot \text{congestion}(i, j, t)$$

Where:
- $\alpha, \beta, \gamma \ge 0$ with $\alpha + \beta + \gamma = 1.0$ (tunable preference weights).
- $\text{travel\_time}(i, j, t) = \text{free\_flow\_time}(i, j) \cdot \theta(t)$.
- $\theta(t) \ge 1.0$ is the dynamic traffic congestion multiplier derived from multi-peak Gaussian rush hour profiles:
$$\theta(t) = 1.0 + \sum_{p \in \text{Peaks}} \alpha_p \cdot \exp\left(-\frac{(t - \mu_p)^2}{2 \sigma_p^2}\right)$$

### 1.2 Multi-Vehicle Objective Function
Minimize the global fleet cost $F$ across all vehicles $k \in \{1, \dots, K\}$:
$$F = \sum_{k=1}^K \sum_{(i, j) \in \text{route}_k} w(i, j, t) + \lambda_{\text{cap}} \cdot \text{Penalty}_{\text{Capacity}} + \lambda_{\text{tw}} \cdot \text{Penalty}_{\text{TimeWindow}}$$

**Subject to Constraints:**
1. **Node Visitation Coverage:** Each customer node $i \in \{1, \dots, n\}$ is visited exactly once by exactly one vehicle route.
2. **Depot Invariant:** Every vehicle route begins and terminates at Depot node $0$.
3. **Vehicle Capacity Limit:** $\sum_{i \in \text{route}_k} \text{demand}(i) \le Q \quad \forall k \in \{1, \dots, K\}$.
4. **Time Window Feasibility:** Customer $i$ service start time $s_i \in [e_i, l_i]$.

## 2. Quantum-Behaved Particle Swarm Optimization (QPSO)

### 2.1 Physics Foundation: Delta Potential Well Model
In classical PSO, particles follow deterministic Newtonian kinematics with position $x_i$ and velocity $v_i$. This makes classical PSO susceptible to premature convergence in local minima on high-dimensional NP-hard combinatorial spaces.

In **QPSO**, particles behave like quantum wave packets bound within an attractive **Delta Potential Well** centered at the local attractor $p_i$. The state of a particle is described by a wave function $\psi(x)$ solving the stationary Schrödinger equation:
$$\left[-\frac{\hbar^2}{2m} \frac{d^2}{dx^2} - \gamma \delta(x - p)\right] \psi(x) = E \psi(x)$$

The probability density function for particle position collapse is:
$$Q(x) = |\psi(x)|^2 = \frac{1}{L} \exp\left(-\frac{2 |x - p|}{L}\right)$$
where $L = \frac{1}{\beta}$ is the characteristic quantum well width.

By applying the Monte Carlo inverse transform method ($u \sim U(0, 1)$), the quantum position update is derived:
$$x_i(t+1) = p_i \pm \beta \cdot |mbest - x_i(t)| \cdot \ln\left(\frac{1}{u}\right)$$

### 2.2 Mathematical Operators of QPSO
1. **Mean Best Position ($mbest$):**
   $$mbest = \frac{1}{N} \sum_{i=1}^N pbest_i$$
   $mbest$ provides collective swarm guidance without storing classical velocity vectors.

2. **Local Quantum Attractor ($p_i$):**
   $$p_i = \phi \cdot pbest_i + (1 - \phi) \cdot gbest, \quad \phi \sim U(0, 1)$$

3. **Contraction-Expansion Coefficient ($\beta$):**
   Dynamic parameter linearly scheduled to balance global quantum exploration and local convergence:
   $$\beta(t) = \beta_{\max} - (\beta_{\max} - \beta_{\min}) \cdot \left(\frac{t}{T_{\max}}\right)$$
   Standard range: $\beta_{\max} = 1.0 \to \beta_{\min} = 0.5$.

### 2.3 Discrete Mapping: Random-Key Encoding (RKE)
Since VRP is combinatorial, continuous quantum positions $X_i = [x_{i,1}, x_{i,2}, \dots, x_{i,D}]$ in $\mathbb{R}^D$ are mapped to valid permutation routes by sorting the indices in ascending order of coordinate values:
$$\pi = \text{argsort}(X_i) + 1$$
This guarantees that all candidate solutions generated by quantum wave collapse are valid permutations without duplicate customer visits.

## 3. QPSO Complete Pseudocode

```text
Algorithm: Quantum-Behaved Particle Swarm Optimization (QPSO) for VRPTW
Input: Road network G, Distance Matrix D, Time Matrix T, Customer nodes, Fleet K, Max_Iter, Swarm_Size N
Output: Global Best Multi-Vehicle Routes (gbest) & Convergence Trace

1.  Initialize N quantum particles X[i] uniformly in [-10, 10]^D
2.  For each particle i in 1..N:
3.      route = Decode_Random_Keys(X[i])
4.      fitness = Evaluate_Route_Fitness(route, D, T, Constraints)
5.      pbest[i] = X[i], pbest_fitness[i] = fitness
6.  gbest = argmin(pbest_fitness), gbest_fitness = min(pbest_fitness)
7.  Initialize convergence_history = [gbest_fitness]

8.  For iteration t = 1 to Max_Iter:
9.      beta = beta_max - (beta_max - beta_min) * (t / Max_Iter)
10.     mbest = (1 / N) * sum(pbest[i] for i in 1..N)
11.
12.     For each particle i in 1..N:
13.         phi = random_uniform(0, 1, size=D)
14.         p_attr = phi * pbest[i] + (1 - phi) * gbest
15.         u = random_uniform(0, 1, size=D)
16.         sign = random_choice([-1, +1], size=D)
17.
18.         // Quantum Wave Collapse Step
19.         X[i] = p_attr + sign * beta * abs(mbest - X[i]) * ln(1 / u)
20.
21.         // Discrete decoding & constraint penalty evaluation
22.         new_route = Decode_Random_Keys(X[i])
23.         new_fitness = Evaluate_Route_Fitness(new_route, D, T, Constraints)
24.
25.         If new_fitness < pbest_fitness[i]:
26.             pbest[i] = X[i]
27.             pbest_fitness[i] = new_fitness
28.             If new_fitness < gbest_fitness:
29.                 gbest = X[i]
30.                 gbest_fitness = new_fitness
31.
32.     // Periodic 2-Opt local search polish
33.     If t % local_search_freq == 0 or t == Max_Iter:
34.         polished_route, polished_cost = Apply_2Opt(Decode_Random_Keys(gbest))
35.         If polished_cost < gbest_fitness:
36.             gbest_fitness = polished_cost
37.
38.     convergence_history.append(gbest_fitness)
39.
40. Return Decoded gbest routes, gbest_fitness, convergence_history
```

## 4. Benchmark Comparison Set
As specified in Problem Statement 26137, QPSO is rigorously benchmarked against:
1. **Classical PSO:** Deterministic velocity-vector baseline proving the superiority of wave-function collapse over momentum vectors.
2. **Genetic Algorithm (GA):** Order Crossover (OX) and Inversion Mutation demonstrating evolutionary vs quantum convergence rates.
3. **Ant Colony Optimization (ACO):** Pheromone matrix $\tau_{ij}$ swarm intelligence baseline.
4. **Exact Methods / Dijkstra & A\*:** Combinatorial branch-and-bound baseline ensuring ground-truth validation on controlled subgraphs.
